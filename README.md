Code for high quality rendering for avatars generated by **[SOAP](https://github.com/TingtingLiao/soap)**. 


## Install 
```bash 
bash install_blender.sh 

pip install -r requirements.txt
``` 
 
# Render 
```bash
python render.py \
  --data_dir {SOAP-DIR}/output/examples \
  --subject 00 \
  --exp newest \
  --driven 0000  
```
